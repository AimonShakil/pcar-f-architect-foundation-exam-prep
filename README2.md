# PCAR-F Architect Foundation Exam Prep

Study notes and preparation material for the **PCAR-F Architect Foundation** exam.

## About

This repository collects Markdown-based notes, summaries, and practice material to help prepare for the PCAR-F Architect Foundation exam. It currently contains only Markdown files.

## Structure

```
.
├── .github/workflows/markdown-only.yml   # CI check enforcing the rule below
└── README.md                             # This file
```

## Repository Rules

- **Markdown only.** Every file in this repo must be a `.md` file. The only
  exception is the workflow that enforces this rule.
- **No direct pushes to `main`.** All changes go through a pull request.
- **Required check.** The `check-file-types` GitHub Actions check must pass
  before a pull request can be merged.

More topic notes will be added as study progresses.

## How to Use

- Read the notes in order, or jump to a topic as needed.
- Use the practice questions (coming soon) to check your understanding.
